> **Archery Technocrats Private Limited (ATPL Group)** is an enterprise engineering leader delivering mission-critical AIDC hardware, GS1 serialization, vision AI, warehouse management (WMS), and interactive 3D digital twin factory simulators.

---

## 🚀 Key Features

- **🤖 Interactive 12-Station 3D Factory & Robot Tour**:
  - Real-time animated traveling robot route along shop-floor assembly stations.
  - Interactive hotspot pins for each hardware and software station.
  - Dynamic typewriter lesson console with station explanations and instant inquiry routing.
- **🏷️ Complete Hardware Catalog**:
  - Fixed UHF RFID portals & dock door antennas.
  - Industrial barcode scanners & rugged handheld terminals (Datalogic, Honeywell, Zebra).
  - High-speed thermal label printers & automatic 120 packs/min print-and-apply applicators.
  - Direct Part Mark (DPM) 2D verifiers & sub-millimeter vision AI cameras.
- **💻 Enterprise Software Suite**:
  - **PERFECT STORE™ (WMS)**: Industrial warehouse management & ERP/PLC middleware sync.
  - **PERFECT TRACE™**: GS1 item-to-pallet parent-child serialization & aggregation.
  - **PERFECT AUDIT™**: 100% paperless digital ISO checklists & CAPA compliance.
  - **PERFECT PMS™**: Real-time Overall Equipment Effectiveness (OEE) and shop-floor monitoring.
  - **PERFECT VISION AI™**: Deep learning optical defect detection.
  - **PERFECTEDGE MDM™**: Centralized rugged mobile device management & lockdown kiosk.
- **📱 100% Mobile Responsive Design**:
  - Fully responsive on all mobile viewports (iOS / Android) and desktop screens.
  - Slide-out mobile navigation drawer with touch accordions.
- **🔒 Admin Control Center**:
  - Real-time CRM lead management, factory station configuration, product catalog editor, and service desk SLA monitoring.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/raihanabanu231-maker/ATPL-website.git

# Navigate to project folder
cd ATPL-website

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Building for Production
```bash
npm run build
```
